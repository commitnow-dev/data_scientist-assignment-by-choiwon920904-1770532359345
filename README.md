### 👀 과제의 설명

**과제 가이드**

마케팅사이언티스트 주니어 채용 과제와 동일한 수준으로 제작되었습니다.

​

**개요**

이 과제는 **복귀 유도 마케팅 캠페인 효과 분석**입니다.
회사는 최근 이탈 유저를 대상으로 문자(SMS) 캠페인을 진행했습니다.
일부 유저에게는 “혜택 중심 메시지(benefit)”, 다른 일부에게는 “감성 중심 메시지(nostalgia)”를 보냈고,
나머지 유저들은 대조군으로 두었습니다.

당신은 마케팅 데이터 분석팀의 데이터 사이언티스트로서
이번 캠페인이 **실제로 복귀율을 높였는지**,
그리고 **어떤 유형의 유저가 광고에 더 잘 반응했는지**를 파악해
다음 캠페인의 타겟팅 전략을 제안해야 합니다.

데이터는 아래 세 가지 파일로 제공됩니다.

| **파일**             | **설명**                        |
| ------------------ | ----------------------------- |
| user\_info.csv     | 유저의 기본 속성 정보 (성별, 나이, 과금수준 등) |
| campaign\_info.csv | 실험군/대조군 및 문자 발송 관련 정보         |
| access\_log.csv    | 유저의 접속 기록 로그 (발송 전후 약 90일치)   |

이 데이터를 활용해, **실험 설계 검증 → 효과 분석 → 타겟 전략 제안**까지의 과정을 수행해 주세요.

***

**요구사항**

분석의 단계나 방법론은 자유롭게 선택할 수 있습니다.
다만 아래 세 가지 질문에 대해서는 필수적으로 답을 **근거와 함께** 제시해 주세요.

1. **실험 설계에 문제가 없나요?**

   * 실험군과 대조군이 잘 섞여 있었는지, 유저 속성(성별, 과금 수준, 최근 접속일 등) 간에 편향이 있었는지 확인해 주세요.
   * 만약 불균형이 존재한다면, 그 원인과 영향 그리고 해결 방법을 설명해 주세요.
2. **광고(문자 캠페인)는 실제로 효과가 있었나요?**

   * 단순 복귀율 비교뿐 아니라, 가능한 경우 인과추론(ATE 등)을 통해
     &#x20;“광고가 복귀율을 얼마나 높였는가”를 정량적으로 보여주세요.
   * 메시지 유형(benefit vs nostalgia) 간 차이가 있다면 함께 분석해 주세요.
3. **다음 복귀 마케팅에서는 누구에게 발송하는 게 가장 효과적일까요?**

   * 어떤 유형의 유저가 특히 반응이 좋았나요?
     &#x20;(예: 이탈 기간이 짧은 무과금 유저, 중간 이탈의 중과금 남성 등)
   * 이런 분석을 바탕으로, **발송 타겟팅 전략** 또는 **메시지 개선 방향**을 제안해 주세요.

참고:
&#x20;단순히 통계적으로 유의하다에서 멈추지 말고,
&#x20;“그래서 실무적으로 어떻게 활용할 수 있을까?”까지 생각해 주면 좋습니다.
